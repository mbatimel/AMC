### FSD (Quick rules)

#### Next.js
- `src/app/` — маршруты Next.js + слой FSD `app` (`layout.tsx`, `page.tsx`, `not-found.tsx`).
- `src/views/<PageName>/` — слайсы слоя FSD `pages` (не `src/pages/` — зарезервировано Next.js).

#### Слои и импорты
- Сверху вниз: `app/ -> pages/ -> widgets/ -> entities/ -> shared/`.
- Импорт разрешен только из нижнего слоя в верхний.
- Внутри слоя: импорты между модулями запрещены (кроме `shared` и `entities`).

#### Стримы
- Проекты дополнительно делятся на стримы.
- Импорты между стримами запрещены, кроме импортов из `core`.

#### Сегменты и структура
- Сегменты внутри модуля (page/widget) включают опциональные файлы/папки: `api/`, `model.ts`, `ui/`, `lib.ts`, `messages.ts`, `types.ts`.
- **Корневой компонент страницы** — `views/<PageName>/index.tsx` (папка `PascalCase`, один вход, без отдельного `index.ts`).
- Папка `ui/` — только для **дополнительных** компонентов слайса.
- Компонент в `ui/`: папка `ComponentName/` → `index.tsx` + `ComponentName.module.css`.
- Вложенных сегментов не должно быть.
- `ui` желательно держать плоским (без глубокой вложенности компонентов).

#### Colocation
- По умолчанию код держи рядом с местом использования (в сегментах страницы/виджета).
- Не разносить преждевременно по слоям.
